# Kafka client dependency

The Katalon Kafka consumer test imports `org.apache.kafka.clients.consumer.KafkaConsumer`.
Download a `kafka-clients` JAR compatible with your Katalon Studio/JDK version and all runtime dependencies required by that version from Maven Central, then copy them into this folder and restart Katalon.

This repository intentionally does not include JAR binaries. Keep the selected dependency version documented in your submission and verify compatibility with your Katalon runtime.
